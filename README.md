# Spring-2026-Medline-Case-Competition
XGBoost model built to predict competitor product shortages for a Medline-sponsored case competition. Data included 5,760 SKUs over 52 weeks and almost 100 features. the model catches 77% of competitor backorder episodes while generating a manageable volume of false alerts, with a ROC AUC of 0.868. Competition completed in 72 hours. Spring 2026.
